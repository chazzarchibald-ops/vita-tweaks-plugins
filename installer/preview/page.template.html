Four designs, each 128 x 128 and cut to a circle by the Vita. Choose one.

Rows on the home screen, beside the Engram Installer and CyberFlow Launcher bubbles.

App screen

The installer as the Vita shows it, 960 x 544. It opens on My other projects.

Enter and back follow the Vita's own setting: X enters and O goes back, or the other way round on a Japanese Vita or with HENkaku's O Button Behavior changed. The button beside Pause switches the preview between the two.

The liquid is drawn by the same code as on the Vita, carried over line for line, so the motion, colours and shading are what the console shows. The text is in the app's own two fonts, Poppins and Righteous for the name, though the Vita draws the letters with its own font library, so their spacing can differ a little. Nothing is installed from this page, and it doesn't go online: choosing Install or update, Uninstall or Check for a new version only shows what the app would report, and so does installing one of the other projects. On the Vita, each project's photos, releases, notes and download sizes come from GitHub as the window opens (and are kept on the memory card); here they are stand-ins from when this page was made: Engram's notes are written for the mockup, not copied from its releases.
